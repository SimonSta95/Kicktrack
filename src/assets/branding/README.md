# Kickbase Brand Assets

Keep the licensed Kickbase brand files local to your project.

Expected public logo path used by `BrandLogo.tsx`:

- `public/branding/kickbase-wordmark-white.svg`

Font family tokens used by the UI:

- Display/headlines: `KB Pitch`
- UI/body: `KB Volksans`

Add the matching licensed font files to your local project and declare them with `@font-face` at the top of `src/styles/globals.css`.

The generated review ZIP intentionally does not redistribute font binaries.
