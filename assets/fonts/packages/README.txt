PRIVATE KICKBASE FONT PACKAGES
==============================

For private/local use, place the two original font packages here with these names:

  KB_Volksans.zip
  KB_Pitch.zip

Nothing needs to be installed into Windows.
KickTrack detects these ZIPs on startup, extracts only the desktop faces it needs
into the user's local cache and registers them with Qt for this process only.

The ZIPs themselves are intentionally not included in this generated project archive.
If your private repository's licensing/use terms allow it, add your own original ZIPs
to this folder and commit them there.
